# بصيرة

شغّل run_site.bat ثم افتح http://127.0.0.1:8000

- index.html: الصفحة والتنسيق وكود إرسال الطلبات، بدون مكتبات JavaScript.
- app.py: الربط بخدمات التحليل والشات والبحث. الروابط والمفتاح في أوله.
- requirements.txt: مكتبات بايثون اللازمة.

المحادثة تبقى بعد تحديث الصفحة في نفس التبويب. زر «محادثة جديدة» يمسحها.
نرسل سجل المحادثة كاملًا إلى خدمة الشات حتى تستخدم المعلومات السابقة.

التحليل والشات والبحث تحتاج خدمات الزملاء شغالة.
لا ترفع app.py إلى مستودع عام لأنه يحتوي على مفتاح الخدمة.
